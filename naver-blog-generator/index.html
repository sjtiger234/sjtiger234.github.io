네이버 블로그 포스팅 생성기

사진과 전체 내용 요약만 넣으면 소제목 구성 · 사진 배치 · 본문 · 총평 · 태그까지 자동으로 완성해드려요.

사진마다 캡션에 "은각사 입구", "정원 풍경"처럼 짧게 적어주시면, 그 단어가 들어간 소제목·문단 근처에 해당 사진이 자동으로 배치됩니다(AI 모드는 그 소재를 본문에서 직접 언급하기도 해요). 캡션을 안 적으면 남는 사진은 순서대로 균등하게 배치됩니다.

소제목 구성은 자동으로 처리됩니다. 내용을 더 추가하고 싶으면 이 칸에 줄을 더 적으시면 되고, 길이 제한은 없습니다. AI 모드는 구글 검색으로 기본 정보(주소·영업시간·가격 등)와 배경 정보까지 찾아 반영하며, 분량 제한 없이 내용에 맞게 상세히 작성합니다.

Google AI Studio에서 무료로 API 키를 발급받아 붙여넣으면, 먼저 구글 검색으로 장소·공연·인물에 대한 실제 정보를 취재하듯 찾은 뒤 입력하신 메모와 합쳐 기본 정보 박스, 배경 소개, 상세 후기까지 갖춘 글로 정리해줍니다(검색 연동 실패 시 메모만으로 다듬는 방식으로 자동 전환). 분량은 제한 없이 내용에 맞게 상세하게 작성됩니다. 검색 연동은 하루 약 1,500건까지 무료이고, 개인 블로그 포스팅 용도로는 무료 한도를 넘길 일이 거의 없어요. 이 사이트는 서버가 없어 키가 브라우저에만 저장되고 Google API로 직접 전송되며, 아래 "사진 내용도 분석해서 반영하기"가 켜져 있으면 사진(최대 30장, 축소본)도 함께 Gemini로 전송되어 실제 내용이 글에 반영됩니다. 사진 전송을 원치 않으면 이 토글을 꺼주세요 — 그럴 경우 캡션 텍스트만 참고해 글을 씁니다. 무료 티어는 Google이 품질 개선 목적으로 요청 내용을 활용할 수 있다는 점도 참고해주세요.

⚠️ 참고: 구글이 최근 발급하는 AQ.로 시작하는 신형식 키는 현재 구글 쪽 버그로 401 오류가 발생할 수 있어요(이 도구의 문제가 아닙니다). 안 되면 아래 "Claude로 작성하기"를 대신 이용해보세요.

아래 버튼으로 프롬프트를 복사해서 claude.ai나 이미 쓰고 계신 클로드 대화창에 붙여넣고 답변을 받으세요. 그 답변 전체(설명 문구 포함해도 괜찮아요)를 아래 칸에 붙여넣고 "가져오기"를 누르면 사진 배치까지 자동으로 완성됩니다. API 키가 필요 없고, 이미 클로드를 쓰고 계시다면 완전히 무료예요.

⚠️ 매번 새 대화(New Chat)에서 프롬프트를 붙여넣어 주세요. 기존 대화창에 이어서 붙여넣으면 클로드가 그 대화의 이전 답변 말투(예: "~다"체)를 그대로 이어가려는 경향이 있어서, 문체 지침이 잘 안 지켜질 수 있어요.

사진과 입력 내용은 저희 서버로 전송되지 않고 이 브라우저 안에서만 처리돼요. (사진은 새로고침 시 사라지므로 완성 후 내보내기를 먼저 해주세요) AI 다듬기를 켜면 텍스트 메모가 Google Gemini API로 전송됩니다.

📈 네이버 블로그 채널(C-Rank) 관리 팁 — 이건 이 글 한 편이 아니라 블로그 운영 전체에 해당돼요
  • 맛집·여행·공연·제품 중 한두 주제로 카테고리를 좁혀서 꾸준히(주 2~3회 이상) 발행하면 C-Rank(채널 신뢰도)에 유리해요.
  • 사진은 반드시 직접 촬영한 사진을 쓰세요. 스톡 이미지나 다른 글 사진 재사용은 오히려 감점 요인이에요.
  • 발행 후 이웃 댓글에 답글을 달고, 관련 글에 방문·소통하면 재방문율·공감 지표에 도움이 돼요.
  • 글 하나의 체류시간이 길수록(평균 2분 30초~3분 이상 목표) 상위 노출에 유리하니, 완성 후 실제로 끝까지 읽어보며 지루한 구간이 없는지 확인해보세요.

이 도구는 입력하신 메모를 자연스러운 문장으로 다듬고, 사진을 본문 흐름에 맞게 배치해주는 보조 도구예요. 생성된 글은 붙여넣기 전에 한 번 더 읽어보고 다듬어 주세요.
